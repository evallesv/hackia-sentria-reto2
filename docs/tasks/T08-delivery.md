# T08 · Publicación y paquete de entrega

Dependencia: T07 para cierre; documentación puede adelantarse. Responsable propuesto: Santiago, representante por confirmar. 30-45 min.

**Editar:** README, docs/delivery/, docs/user-guide.md, registro JSON de herramientas y PDF generado. No cambiar código ni LICENSE.

1. Actualizar estado real y guía de uso; URL pública verificable, modo Gemini, formatos y límites.
2. Completar registro de herramientas: nombre/modelo exacto si se conoce, propósito, aplicación, resultado y evidencia. Separar usado, seleccionado y pendiente. No atribuir OpenCode/Gemini a trabajo que no realizaron.
3. Generar PDF con `uv run --group documents python -m scripts.build_tools_pdf`; revisar páginas visualmente. Completar al cierre; el PDF inicial es solo preparación.
4. Publicar cambios autorizados a GitHub y verificar visibilidad desde sesión no autenticada; si el propietario prefiere PR, abrirlo con descripción y tests. No cambiar visibilidad/licencia implícitamente.
5. Completar delivery/submission.md con repo, agente y PDF. Confirmar fecha/extensión y representante. El correo queda en borrador; enviar solo por instrucción explícita del usuario.
6. Video opcional de 2-3 minutos: problema, caso B o C, evidencia, control A, arquitectura y límites. No presentarlo como entregable obligatorio de estas bases.

**Aceptación:** tres entregables accesibles, sin placeholders; PDF consistente con versión desplegada; licencias/atribución; integrantes correctos; checklist honesto; confirmación de plazo registrada si existe. No marcar envío realizado sin evidencia.
